# Start and navigation

The **Start** page introduces the active project, shows its recent activity and links to the main parts of the Compositor. Use the navigation across the top to move between **Objects**, **Stories**, **Glossary**, **Home and Pages**, **Site settings** and **Publish**.

## Site preview

Edit your exhibition's landing-page content in **Home and Pages**. The **Start** page is a project overview; it is not the editor for the public homepage.

## Welcome message

Open **Home and Pages** to edit the introduction that visitors see on your site. Review the site's title, description and interface language in **Site settings**. Publish when you want these changes to reach the public site.

## Stories

The **Stories** page lists the narratives in your exhibition.

### View and open stories

Choose **Edit** on a story to open the [Story Editor](/docs/the-compositor/story-editor/). Each row shows its title and number of steps.

### Create a new story

1. Choose **+ New Story**.
2. Enter a title and, if needed, a subtitle and byline.
3. Choose **Save** to create the story and open its editor.

### Reorder stories

Drag a story by its handle to change the order in which stories appear on the public site. The new order is included when you publish.

### Delete a story

Use **Delete story** and read the confirmation before continuing. Your public site changes when the deletion is published. Check the available **Undo** control if you removed something by mistake.

### Draft and private toggles

- **Draft** excludes a story from the public exhibition. Use it while preparing work that should not appear.
- **Private** controls access to the story's content. Read [Private Stories](/docs/site-features/private-stories/) before relying on this for a project.

## Project switching

Use the project name in the header to switch between connected sites. Each site has its own collection, stories and unpublished changes.

## Status bar

The header shows the connection state and whether the active project has unpublished changes. Wait for the connection to be ready before editing. Use **Publish** to review the changes and follow the resulting site build.

The collaboration control opens information about the project's team and activity. Your user menu leads to **Account**, where **Interface language** changes the Compositor's labels. It does not translate your exhibition's text; the public site's interface language is a separate setting.
