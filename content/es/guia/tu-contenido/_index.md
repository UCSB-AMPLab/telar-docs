# Tu contenido {#tu-contenido}

Los objetos, las historias, los paneles y las páginas de apoyo forman la exhibición. Esta referencia explica sus archivos fuente y formatos. Usa el [manual del Compositor](/guia/el-compositor/) para edición visual, el [de Sheets](/guia/google-sheets/) para hojas de cálculo o el [de autoría local](/guia/autoria-local/) para CSV y Markdown. Los tres métodos generan un sitio estático.

- [Objetos](/guia/tu-contenido/objetos/) — Los elementos visuales que tus historias exploran — imágenes, mapas, documentos, fotografías
- [Imágenes autoalojadas](/guia/tu-contenido/imagenes-autoalojadas/) — Sube tus propias imágenes y Telar genera teselas ampliables automáticamente
- [Imágenes IIIF externas](/guia/tu-contenido/iiif-externo/) — Usa imágenes de museos, bibliotecas y otros proveedores IIIF
- [Historias y paneles](/guia/tu-contenido/historias-paneles/) — Narrativas paso a paso construidas alrededor de tus objetos, con paneles de detalle expandibles
- [Contenido enriquecido con Markdown](/guia/tu-contenido/contenido-enriquecido/) — Enriquece los paneles de historias con narrativas extensas, medios incrustados y contenido reutilizable
- [Sintaxis de Markdown](/guia/tu-contenido/sintaxis-markdown/) — Referencia de formato para archivos Markdown usados en paneles y páginas
- [Widgets](/guia/tu-contenido/widgets/) — Elementos interactivos para paneles de historias y páginas personalizadas — carruseles, pestañas, acordeones
