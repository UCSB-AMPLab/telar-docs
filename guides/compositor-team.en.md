# Work with a team

Team members work on the same project in the Compositor. The project role and GitHub repository access are related but separate: someone may be able to edit in the Compositor while a GitHub invitation still needs attention.

## Invite a collaborator

The convenor can use the project's team controls to choose **+ Invite Collaborator** and enter a GitHub username.

If that person already has a Compositor account, the project can be added to their account. Otherwise, the Compositor supplies an invitation link for you to share within 48 hours. Check the pending invitations list if they have not joined.

Invite the account the person actually uses to sign in. A display name or email address is not a GitHub username.

## Understand project roles

- The **convenor** manages project membership and structural settings.
- A **collaborator** edits content and can publish, upload files and run an upgrade.
- An **instructor** receives editorial access through a course and has the same publishing rights.

Some structural controls, including creating glossary entries and changing their IDs, belong to the convenor. Deletion controls also consider who created an item. The interface explains when your role cannot perform an action.

## Check repository access

Open **Repository access** to see the GitHub status for each member. A pending invitation needs acceptance; an expired invitation can be reissued by the convenor.

Members can accept their own invitation from this page or follow the GitHub invitation link if the Compositor cannot accept it. The convenor can add or withdraw repository access for other members where the controls allow it.

Publishing uses the installed GitHub App. A successful Compositor publish does not by itself confirm that every member has accepted personal GitHub access.

## Coordinate edits and publication

Wait for the collaboration connection to settle before starting. Agree who will edit a passage and who will publish the shared changes. Review the publication list together when several people have been working.

Removing a collaborator takes away project access. Course instructors are managed through the course and cannot be removed individually while the site remains attached to it.

**Check your work:** ask the collaborator to sign in, open the intended project and confirm their role. Continue with [course projects](/docs/the-compositor/courses/) if you are teaching a class.
